# ツール台帳

実装の規則は [../TOOL-SPEC.md](../TOOL-SPEC.md)。カードのひな形は [_TEMPLATE.md](_TEMPLATE.md)。
`npm run check` が、コレクションと拡張のそれぞれにカードがあることを検査する。
